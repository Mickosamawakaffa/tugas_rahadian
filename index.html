Konsep Struktur Data dalam Aplikasi Ini

Array of Struct

Array dataProduk[] menyimpan kumpulan objek produk. Setiap objek memiliki field: kode, nama, kategori, harga, stok, gambar. Dibuat lewat fungsi buatProduk().

Pointer / Referensi

Variabel ptrProdukDipilih menunjuk ke objek di array. Perubahan melalui pointer (misal kurangi stok) langsung mengubah data di array utama.

Bubble Sort

Sorting manual tanpa Array.sort(): bandingkan elemen berdekatan, tukar jika urutan salah, ulangi sampai terurut. Setiap langkah tercatat di log.

Binary Search

Pencarian efisien pada data terurut: bagi dua area pencarian setiap langkah. Data otomatis diurutkan berdasarkan kode sebelum pencarian dimulai.

Sequential Search

Pencarian linear dari awal sampai akhir array. Digunakan untuk mencari berdasarkan nama produk (data tidak harus terurut).
